# El viaje a La Sabana

Guía interactiva para familias de estudiantes foráneos de la Universidad de La Sabana (programa *La Sabana, tu segundo hogar*).

- Mapa de Colombia por departamentos con los datos de la caracterización de foráneos 2026-1 (1.866 estudiantes).
- Pase de viaje personalizado por región y pasaporte con cinco paradas: Llegar, Vivir, Cuidarse, Crecer y Acompañar.
- Página estática en un solo archivo (`index.html`), sin backend. Se puede publicar directamente en Vercel o GitHub Pages.

Las secciones marcadas como "Por completar" (vivienda, transporte, fechas para familias) tienen contenido de ejemplo pendiente de validar.
